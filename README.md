# E-Learning Platform

A frontend e-learning website I built to practice and strengthen my HTML, CSS, and JavaScript skills.

## Features

- Home page
- Courses page
- Login page UI
- Signup page UI
- Responsive layout
- JavaScript interactions
- Organized frontend structure

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` — Home page
- `courses.html` — Courses page
- `login.html` — Login page
- `signup.html` — Signup page
- `style.css` — Website styling
- `script.js` — JavaScript functionality
- `assets/` — Project assets

## What I Learned

This project helped me practice building multiple webpages, creating forms, styling layouts, and adding interactivity with JavaScript.
